# 인력공급 업무 키트 (베트남 단기 근로자)

단기 근로자 인력공급 업무에 쓰는 **계획/실적표(Excel)**와, 고객사마다 반복해서 보내는 **제안서(PPT) 자동 생성기**입니다.

```
labor-kit/
├── 계획실적표_템플릿.xlsx        ← 바로 열어서 사용
├── 예시_제안서_차량미지원.pptx    ← 생성 결과 예시 (고객사 차량지원 없음)
├── 예시_제안서_차량지원.pptx      ← 생성 결과 예시 (고객사 셔틀 있음)
├── build_workbook.py            ← 엑셀 양식을 다시 만들 때만 사용
└── proposal/
    ├── generate.js              ← 제안서 생성기
    ├── data/company.json        ← 우리 회사 정보 (한 번만 작성)
    ├── data/clients/*.json      ← 고객사별 정보 (고객사마다 1개)
    └── output/                  ← 생성된 제안서 (git 제외)
```

---

## 1. 계획/실적표 (`계획실적표_템플릿.xlsx`)

| 시트 | 하는 일 |
|------|---------|
| 안내 | 사용법, 색상 범례 |
| 고객사 | 고객사 코드·단가·**고객사 차량지원(Y/N)**·지원형태·픽업지점·자사차량비 |
| 일일계획실적 | 날짜 / 고객사코드 / 직무 / 교대 / 계획 / 실적 / 자사 차량 운행 대수만 입력 → 달성률·결원·매출·인건비·차량비·이익 자동 계산 |
| 월간요약 | 기준월(C3)만 바꾸면 고객사별 연인원·달성률·매출·이익과 일자별 차트가 갱신 |
| 목록 | 직무·교대·지원형태 드롭다운 항목 |

- 노란 칸 = 입력, 회색 칸 = 자동 계산(지우지 말 것)
- 헤더는 한국어/베트남어를 함께 표기해 현장 관리자도 쓸 수 있습니다.
- **차량 관련 자동 체크**: 고객사 차량지원이 `N`이고 지원형태가 `자사 차량 운행`인데 자사 차량 대수를 0으로 입력하면 `차량 미배정`이 빨간색으로 표시됩니다.
- 달성률 90% 미만(일일)·95% 미만(월간)은 빨간색으로 표시됩니다.
- C001~C004 고객사와 2026년 9월 데이터는 **예시**입니다. 노란 칸의 예시 값만 지우고 쓰세요.

## 2. 제안서 생성기 (`proposal/`)

### 처음 한 번만

```bash
cd labor-kit/proposal
npm install
```

그리고 `data/company.json`에 우리 회사 정보(회사명, 실적 수치, 레퍼런스, 연락처)를 실제 값으로 채웁니다. **지금 들어 있는 숫자와 사례는 모두 예시입니다.**

### 고객사가 생길 때마다

1. `data/clients/예시_대성섬유.json`을 복사해 `data/clients/<고객사명>.json`으로 저장
2. 고객사명, 과제(needs), 공급 계획(plan), 차량지원(vehicle), 단가(pricing), 조건(terms)만 수정
3. 실행

```bash
node generate.js data/clients/<고객사명>.json   # 한 곳
npm run all                                     # 폴더 전체 일괄 생성
```

→ `output/제안서_<고객사명>_<날짜>.pptx`가 만들어집니다. PowerPoint에서 열어 그대로 수정할 수 있습니다.

### 제안서 구성 (11장)

1. 표지 (고객사명 자동) · 2. 회사 소개(핵심 수치) · 3. 고객사 과제 → 해결 방향 · 4. 인력 공급 계획(합계·월 연인원 자동)
5. 운영 프로세스 · 6. **출퇴근 차량 지원 방안** · 7. 품질·법규 준수 · 8. 공급 실적 차트(계획 vs 실적)
9. 견적(예상 월 비용 자동 계산) · 10. 주요 사례 · 11. 계약 조건·다음 단계·연락처

**차량 지원 슬라이드는 `vehicle.clientSupport` 값에 따라 자동으로 바뀝니다.**
- `true` → "고객사 셔틀 연계 운영" (탑승 명단 공유 → 픽업 지점 관리 → 지각·이탈 관리)
- `false` → "당사 차량 운영 제안" (운행 차량·노선·비용과 청구 방식)

### 입력 팁

- 과제(needs)는 최대 4개, 품질 항목은 6개, 사례는 4개까지 표시됩니다.
- 견적의 `role`을 공급 계획의 `role`과 같게 쓰면(또는 `직무(교대)` 형식) 예상 월 비용이 자동 계산됩니다.
- 8번 실적 차트는 `company.json`의 `performance`를 씁니다. 계획실적표 **월간요약** 합계의 계획/실적 연인원을 매달 옮겨 적으세요.
- 폰트는 맑은 고딕(Malgun Gothic)입니다.

## 3. Claude Code로 더 빠르게

이 저장소에는 `/proposal` 스킬이 들어 있습니다. Claude Code에서

```
/proposal 한빛전자 비나, 박닌, 생산 35명 주간 + QC 15명 야간, 셔틀 있음, 단가 42만/46만
```

처럼 말하면 고객사 JSON 작성 → 제안서 생성 → 검수까지 한 번에 진행합니다.

## 엑셀 양식을 수정하고 싶을 때

`build_workbook.py`를 고친 뒤 `python3 labor-kit/build_workbook.py`를 실행하면 양식이 다시 만들어집니다 (openpyxl 필요). **입력해 둔 데이터는 덮어써지니** 사용 중인 파일은 다른 이름으로 보관하세요.
